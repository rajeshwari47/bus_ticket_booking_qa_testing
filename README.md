## Bus Ticket Booking Application – QA Testing Project

## Project Overview

This project focuses on testing a Bus Ticket Booking Application to validate its functionality, usability, and end-to-end booking flow.

The application includes modules such as bus search, seat selection, passenger details, booking, payment, and booking confirmation.

## Testing Activities

* Designed and executed 40+ test scenarios and test cases
* Performed Functional Testing
* Performed UI Testing
* Performed Smoke Testing
* Performed Regression Testing
* Tested end-to-end search and booking workflows
* Applied Boundary Value Analysis (BVA)
* Applied Equivalence Partitioning (EP)
* Documented defects with reproduction steps
* Assigned appropriate severity and priority to defects
* Automated critical search and booking workflows using Selenium WebDriver

## Modules Tested

* Bus Search
* Bus Selection
* Seat Selection
* Passenger Details
* Booking
* Payment
* Booking Confirmation

## Test Design Techniques

### Boundary Value Analysis

Used boundary values to identify defects at the limits of accepted input.

### Equivalence Partitioning

Divided input data into valid and invalid equivalence classes to design effective test cases.

## Automation Testing

Critical and repeatable workflows were automated using:

* Java
* Selenium WebDriver
* Locators
* XPath

## Defect Reporting

Defects were documented with:

* Bug ID
* Bug Title
* Steps to Reproduce
* Expected Result
* Actual Result
* Severity
* Priority
* Status
